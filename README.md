# Лабораторная работа 7 — Интеграция сторонних JS-библиотек

## Цель работы
Целью лабораторной работы является изучение продвинутых практик взаимодействия с DOM и CSS с использованием сторонних JavaScript-библиотек, а также оформление существующих скриптов в виде ES-модулей.

---

## Используемые библиотеки

1. **Particles.js**  
   - Источник: [https://github.com/VincentGarreau/particles.js](https://github.com/VincentGarreau/particles.js)  
   - Назначение: создание интерактивного фонового эффекта частиц в шапке сайта, который реагирует на движение мыши.  
   - Особенности подключения:
     - Контейнер с id `particles-js` расположен в шапке (`<header>`)  
     - Стиль контейнера задаёт абсолютное позиционирование и размер на всю область шапки  
     - Скрипт `initParticles()` вынесен в отдельный ES-модуль `effects/particles.js`  
     - В `main.js` функция импортируется и вызывается, если контейнер существует

2. **OpenLayers**  
   - Источник: [https://openlayers.org](https://openlayers.org)  
   - Назначение: отображение карты с указанием местоположения музея.  
   - Особенности подключения:
     - Контейнер с id `map` находится внизу страницы (футер / секция «Контакты»)  
     - Карта инициализируется в ES-модуле `map/museumMap.js` функцией `initMuseumMap()`  
     - На карте установлена метка, указывающая точное расположение музея (координаты Санкт-Петербурга)  
     - Возможна масштабируемость карты и перетаскивание мышью
